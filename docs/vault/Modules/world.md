# Modules/world

> [!abstract] Role
> `World` — the contract's spine object (see [[Concepts/Track Kit|Track Kit]]): one object owning physics, scene and the track graph for one run attempt, plus the `Level` shape every role builds against. Owner: Systems Engineer.

## What it does

- `src/world/world.ts` — `World`: `constructor(level, build, opts)` (via `World.create`, which awaits `initRapier` first) reifies the `Build` into ONE fixed body carrying every `spline.toColliderDescs(RAPIER, { scale: SIM_SCALE })` hull (group `TRACK_GROUP` = `0x0001_fffd` — bit0 member, filter EXCLUDING the chassis bit1, matching `src/feel/kittrack.ts`; never the default all-ones group, see [[physics]] gotchas), builds plain-material meshes when `visuals` is on, and spawns the raycast-wheel car from `src/physics/car.ts` at the level's `startSocket`, advanced `SPAWN_ADVANCE` (2 cm) down the tangent (a car centred ON the socket hangs half its wheelbase over the deck edge and slides off backwards — measured, do not re-tune blindly). Track colliders are built with `TRACK_FRICTION` IMPORTED from `src/track/material.ts` — the same rubber every feel rig measures with (it used to be a local 0.6 with a comment claiming it matched the rigs; stage-2 review MAJOR). `buildTrackMeshes(build, options)` is the shared plain-material render path (scene, share card, dev scenes); stage 4's FIXTURE READABILITY SIGNAL (playtest Q handoff) rides its optional `fixtures` table: every fixture-piece occurrence per the SAME `fixtureQuota` rule (`src/track/build.ts` — moved out of `src/boot.ts`, which re-exports) wears a `userData` flag plus a lighter-orange deck inlay (`FIXTURE_SIGNAL` in `src/track/material.ts`), so fixtures read as scenery-marked rails; without the table the render is byte-identical to before and no `PlacedPiece`, hash or par moves.
  - The chassis-excluding filter is load-bearing here too (measured 2026-10-05 with the real feel track in `World`): with the old filter-all `0x0001_ffff` the chassis collider hoovered the loop's ~3 mm chord risers — a 5 m/s² energy-pumped ramp descent and an anchor at the loop bottom, never terminating. Support rays are unaffected (they're cast without a group filter, and the wheel-exclusion predicate reads MEMBERSHIP, not the filter mask), the deck stays visible to suspension; the `wheelColliders` bake-off variant still physically touches the track (bit2 stays filtered-in).
- `step()` is the contract's fixed 1/120 s in the fixed order **inputs → car forces → physics → constraints**: launcher triggers (world `power` enters the sim as a sim-space Δv via `power * SIM_SCALE`) → `carStep` (with the level's hazard `gripAt` field when it has zones — see [[hazards]]; `HazardField.fromLevel` runs once in the constructor, and a zone-free level passes no callback at all) + `applyRollingResistance` (given the step's `support` so per-wheel grip shares apply) → `stepWorld` → state hash every `HASH_INTERVAL` + `observe` (cup capture at `CUP_CAPTURE_FACTOR` radii — plus the stage-3 STALL-CAPTURE: a car that stops with its centre within the capture radius + one chassis half-length of the cup centre is captured, not stalled (the word “seated” now names this cup event and nothing else — the placement ghost’s amber word is `reversed`, see [[ui]]), closing playtest G's “car visibly inside the cup, scored 0” contradiction; measured rim-stall centre distance 0.084 m vs the 0.072 m pure-centre radius, moving captures bit-identical — every par hash and `pars.json` regenerate byte-clean, `tests/unit/world.test.ts` —, fall below the lowest socket − 0.75 m, stall, timeout). Stall is `STALL_SPEED` 0.05 m/s grounded-held for `STALL_SECONDS` 0.5 s (stage-3 latency tune, playtest E: the old 0.02/2 s pair never even fired for a PARKED car — contact-corrector jitter reads 0.02–0.05 m/s of phantom speed, so dead-on-the-deck runs rode to the 12 s timeout; measured before/after in `tests/unit/world.test.ts`: 12 s `timeout` → 0.59 s `stalled`, and the feel-track hash/finish step are bit-identical across the swap — these reads are outcome-only). Stage-4 round 2 (playtest J+K: \"the result lands 2-3 s after the failure is visible\") added the missing half: a car WEDGED off a deck edge reads NOT grounded with speed ~0, so the grounded counter never fills and dead runs rode the 12 s timeout — `SLOW_AIR_SPEED` 0.05 m/s held NOT-grounded for `SLOW_AIR_SECONDS` 1.0 s concludes `stalled` (deliberately slower than the grounded window: every airborne sample of every par run measures >= 0.3 m/s, so no real flight trips it; outcome-only, feel-track hashes pinned unchanged).
- `state()` / `states()` are the renderer's ONLY read (positions converted to world metres); `carPose(alpha)` lerps the last two. `hash()` folds the run seed in (`seededHash`), so hash = f(level, build, seed); NaN poisons via `quant`'s distinct words in `src/physics`.

The optional `parBuild` is the Level Designer's reference build for pars (brief §9.2); `scripts/gen-pars.mjs` falls back to `placeholderBuild` until a level ships one, so the feel track's real-kit chain is its own reference for now.

## Invariants

- A World is constructed from `(level, build, opts)` and nothing else (Track Kit invariant 4). No hidden world state reaches physics; the seed rides in through `build.seed`.
- The renderer never reads physics per frame; the frame loop in `src/boot.ts` only decides how many fixed steps the elapsed time pays for.
- Termination is a function of the data: terminal `status` or a fixed step cap — so replays of equal data execute equal step sequences.

## Known quirk (measured)

Rapier's query pipeline does not see freshly created colliders until the first `world.step()` propagates the broad-phase — the car's first support ray deterministically misses and the car sinks ~0.3 mm at step 0. Same ordering as the `src/feel` rigs, deterministic on every machine; left as-is on purpose.
