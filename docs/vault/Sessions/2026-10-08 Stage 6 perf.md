# Stage 6 — Technical Artist: performance pass

Worktree `gw-ta-p`, branch `stage6-perf`. Built the measurement harness the stage-6 accept line
needed (`tools/perf-table.mjs`, following the `tools/render.mjs` build-serve-drive pattern and the
measurement-A shape of `tests/e2e/perf.spec.ts` / `tests/e2e/perf-stage3.spec.ts`): it probes every
one of the 30 campaign rungs at `?level=<id>&build=par` for per-frame GPU cost, picks each set's
busiest rung by measured draw calls rather than by tray count (a tray is builder inventory, not
meshes — the heaviest-tray rung is rarely the heaviest scene), then runs the ≥5 s simulated-time
verdict on the real shell with the World stepping, sampling `performance.now()` rAF deltas plus
draw calls / triangles / live programs counted at the WebGL command boundary by an init-script
probe (deliberately not `renderer.info`: the game page exposes no renderer seam and adding one to
`src/boot.ts`, which a dozen notes anchor, was the worse trade for an audit), and a 1-pixel
`readPixels` unpaced-cost probe because a 60 Hz-pinned median cannot report its own headroom.
Verdict numbers are hardware GL only — `--use-angle=metal`, and the run aborts if the page reports
SwiftShader — so the stage-3 deferred item ("the integrated-laptop re-measure") is closed on the
reference machine (MacBook Pro, Apple M5 Pro, 20-core GPU, 48 GB, macOS 26.6.2): **kitchen
`kitchen03` 16.70/16.70 ms, bedroom `bedroom02` 16.70/16.70, bathroom `bathroom04` 16.70/16.80,
garden `garden04` 16.70/16.70, garage `garage04` 16.70/16.80, porch `porch04` 16.70/16.70**
(median/p95, post stack ON, 960×540) — 0–1 dropped frames, keep-up 1.00, 2.6–4.5 ms unpaced cost.
**No set missed 60 fps, so §12 triage was not applied and nothing was dropped: no prop cut, no post
cut, no resolution cut.** The GPU-side counts are not equal even though the medians are (porch 108
idle draws vs kitchen 56 at the same 16.70 ms; garden 63.0k triangles in the run window against
garage 7.4k), which is recorded as the early-warning columns rather than a failure. The same six
runs under SwiftShader are recorded separately as CI-truth context only (16.7–66.7 ms medians,
keep-up 0.78–0.91 — the rasteriser, not the game), and the CI budget was measured, not trimmed:
vitest 5.3 s, e2e 2 m 26 s, filmstrip 27.8 s — acceptable, so no test lost a case to this pass.
