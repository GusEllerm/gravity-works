# 2026-10-07 Stage 3 — result screen, help drawer, share card, pars (systems engineer)

## Goal

Ship the stage-3 UI plumbing (brief §10, §9.1, §9.3, §9.4) on branch
`stage3-ui`: the end-of-run result panel with the one-line physics note,
first-time piece callouts and the help drawer with tiny looping renders, the
share-card PNG on the share page, and pars regenerated by script with a CI
drift check. Worktree `/Users/gusellerm/Projects/games/gw-se3`.

## What was done

- `src/world/stars.ts` — pure `starsFor(result, par)` (finish / `<=` par
  pieces / `<=` par time, three independent stars) + `starGlyphs` + the
  pars layer: `parFor` answers from `pars.json` first, level `par` as
  fallback.
- `scripts/gen-pars.mjs` (`npm run pars`, gate `npm run pars -- --check`) —
  replays every registered level's `parBuild` (fallback
  `placeholderBuild`) headless through `src/replay` and writes
  `{levelId, parPieces, parTime}`; parTime = measured finish ceil'd to
  0.05 s; a reference build that doesn't finish exits 2. Shipped
  feeltrack line: 9 pieces / 3.05 s (measured 3.0083 s / 361 steps).
- `src/ui/result.ts` — `createRunRecorder` (five witnesses: apex,
  touchdown pitch, final airtime, last-grounded pitch, last speed-gain),
  `physicsNote` (coverage map in `Modules/ui.md`; catch-all line so the
  note never guesses), `resultModel`, `createResultPanel` — the panel
  over the world, shown only on terminal statuses (§5.11).
- `src/ui/callouts.ts` + `src/ui/help.ts` — 13 one-line piece callouts
  (prop manifest ready for the set modules), `firstSight` recorded in
  `SaveSettings.calloutsSeen` (optional field — no migrade); the drawer
  lists unlocked entries with one shared mini-harness canvas spinning
  each piece at the 12 Hz stop-motion clock, still frames under reduced
  motion.
- `src/share/card.ts` — `generateShareCard(state): Promise<Blob>`:
  hero-attitude bbox-scaled framing of the final build state (Decision
  Log 2026-10-07), warm caption strip with time/stars/URL/verified, PNG
  Blob; `src/boot.ts` wires `#gw-share-card` on the shared-run page.
- `src/boot.ts` — recorder sampling per fixed step, terminal-status panel
  show, `?launch=1` release hook, callout-on-first-place line, help
  drawer mount, share-page card button.
