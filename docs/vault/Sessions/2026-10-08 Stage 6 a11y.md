# 2026-10-08 Stage 6 a11y

## Goal

Stage 6 (Feel Engineer): the accessibility audit + keyboard building end to end + the 820 px and touch pass, on branch `stage6-a11y`. Brief read first (`Concepts/Feel`, `Modules/ui`, `Modules/camera`, Decision Log).

## What was done

- AUDIT with numbers, not vibes: `scripts/a11y-contrast.mjs` computes every UI text/UI pair from the CSS colors (composites + the dimmed states included); live-browser tab walks on the preview build; a tween sweep for Feel's reduced-motion law; the colorblind and label ledger read off the DOM. Every finding, fix or reason, is the table in `Reference/Accessibility audit 2026-10-08`.
- THE HEADLINE BUG: Tab was the tie-walk under world focus — and world focus is the page's DEFAULT state — so the first Tab of a session preventDefaulted into `cycleAim` and focus never moved; no button was ever reachable by Tab. Subtractive fix (Tab leaves the keydown table; `[ ]` keep the tie-walk), a real traversal spec walking the live stop list, and the aim-depth gate updated to walk ties with `]`.
- `L` launches (world focus, same `startRun`, taught on the hint line — two older specs carry the hint verbatim and moved with it). The keyboard end-to-end is now the e2e: kitchen01 Tab-held, Enter-placed ×3, L-launched, panel closed by keyboard, no mouse, no focus().
- Focus rings authored (two-tone #143a6e/#fff8ec, #ffe1a8 on the dark panel — computed-style-asserted, plus tab-stop screenshots in docs/explorations/a11y); contrast bumps (#gw-hash-details → #6a5636, replay ticks → #a34e15, borders → #8a7040); canvas named (role=img + label, describedby the live status line) on both surfaces.
- Reduced motion unified in `src/ui/motion.ts` (save override, OS default): the replay cinematic now defaults to its still frame under the media query (spec-proven), the flip tween snaps to its END pose, the CSS belt block guards future transitions. The camera damping stays — gameplay framing, logged.
- TOUCH: aim at touch-down, two-finger drag = orbit, spread = the browser's pinch zoom (`touch-action: pan-y pinch-zoom`), fresh-intent releases mouse-only, 44 px tap boxes under coarse pointers — e2e-proven at 390x844 AND 820x1180 (tap-to-place the par line, travelling tap pans and never places, two-finger drag orbits, long-press opens no menu).
- Gates on this branch: `npm run test` 695/695; `E2E_PORT=4423 npx playwright test` 181 passed / 1 skipped (the filmstrip lane); the two a11y specs add 13.
